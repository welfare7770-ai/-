# 생활기록장

설치 없이 브라우저에서 바로 쓰는 개인 생활 기록 앱 (`index.html` 한 파일).

| 탭 | 기능 |
|---|---|
| 홈 | 이번 달 수입·지출, 교체 임박 소모품·기한·납부 알림 통합 |
| 가계부 | 수입/지출, 분류별 합계, 월 예산, 연간 월별 합계, 검색 |
| 자동차 | 소모품별 교체주기(km·개월) → 다음 교체 시기 자동 계산, 정비이력, 주유·연비, 보험/검사 기한 |
| 고정지출 | 관리비·통신비·보험료·구독료, 이번 달분 가계부 일괄 기록 |
| 기한관리 | 보험 만기, 정기검사, 면허 갱신, 건강검진, 세금, 기념일 (반복·D-day) |
| 경조사 | 축의금·조의금 주고받은 내역, 이름별 조회 |
| 등산 | 산행 일지(날짜·요일·날씨·기온·코스·거리·걸음수·소요시간·동행·느낀 점), 연간 요약, 100대 명산 진행률 |
| 헬스 | 근력(무게·세트·회), 런닝머신(분·칼로리), 주간 권장량(유산소 150분·근력 2일) 달성률, 운동별 최고기록 |
| 건강 | 혈압·혈당·체중, 당화혈색소·콜레스테롤 검사결과, BMI, 참고 기준표 |
| 설정 | JSON 백업/복원, 가계부 CSV 내보내기, 화면 테마 |

데이터는 사용하는 기기의 브라우저(localStorage)에만 저장됩니다. 주기적으로 백업하세요.
